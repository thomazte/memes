# Memes

**Projeto acadêmico de Desenvolvimento de Soluções WEB.**

Aplicação web para buscar, visualizar e baixar memes (imagens e GIFs), com login, cadastro, perfis de usuário/admin e catálogo local.

## Stack

Java 18 · Jakarta Servlet · Tomcat 10 · Maven · PostgreSQL · HTML/CSS/JS

## Subir rápido

```bash
mvn clean package
# Tomcat local → http://localhost:8080/login
# site publicado → https://memes.137.131.137.227.sslip.io/login
```
